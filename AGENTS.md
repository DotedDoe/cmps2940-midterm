# AI Agent Instructions for CMPS 2940 Midterm Project

## Environment & Tech Stack
- Frontend: HTML5, CSS3 (Bootstrap/W3.CSS permitted), Vanilla JavaScript
- Browser APIs: DOM Manipulation, LocalStorage, Event Handling
- Local Execution: Hosted using `php -S localhost:8000` or `python3 -m http.server 8000`

## Strict Rules & Constraints
1. DO NOT use React, Vue, Svelte, HTMX, Alpine.js, or any frontend JS framework.
2. ALL interactive code MUST be written in pure Vanilla JavaScript.
3. Ensure semantic HTML5 tags and accessible form labels.
4. Structure page layouts for easy eventual conversion into Symfony Twig/HTML templates.
