## Description
Frontend prototype for a small business web application. Built with
HTML5, CSS3, and Vanilla JavaScript — this is the UX foundation for
our full-stack Symfony + PostgreSQL final project.

## Running Locally

Requires PHP installed.

```bash
cd cmps2940-midterm
php -S localhost:8000
```

Then open http://localhost:8000 in your browser.

Alternative (Python 3):

```bash
cd cmps2940-midterm
python3 -m http.server 8000
```
